## 开场 30 秒

各位老师好，我们选择的是 A1“基于多模态大模型技术的设备检修知识检索与作业系统”。我们的定位不是做一个通用维修聊天机器人，而是面向电机、离心泵和轴承三类设备，把故障文本、图片和设备型号转成可追溯的检修证据、可执行的 SOP、可审核的安全合规项，以及可持续更新的知识库。

## 第 2-4 页：问题和主线

检修现场的问题不是完全没有资料，而是资料分散、检索效率低、作业流程不统一、经验难沉淀。所以我们把 A1 的要求收束成一条作业闭环：输入故障信息，先检索手册和案例证据，再做故障判断和 SOP 生成，随后进行合规校验，最后把审核后的案例沉淀回知识库。

这一点很重要：系统不是给一句自然语言答案，而是把检修任务推进到可以复核、可以执行、可以更新的流程里。

## 第 5-8 页：技术路线

系统架构上，前端是 PC Web 工作台，后端用 FastAPI 编排检索、Agent 和知识更新。数据层保留手册、案例、图片描述、评测题和轻量知识图谱；在线部署时使用 Supabase 做持久化，本地仍保留 SQLite 备份。

检索不是单一路径，而是文本检索、向量检索、型号过滤、图片 caption 检索、图谱邻居扩展和重排序的组合。图片输入也不是直接让模型编答案，而是先转成结构化缺陷标签，再回到手册和案例证据。

Agent 编排的目的不是堆概念，而是拆职责：检索 Agent 找证据，视觉 Agent 处理图片，诊断 Agent 排原因，SOP Agent 生成步骤，合规 Agent 检查安全项，更新 Agent 负责审核后的知识沉淀。

## 第 9-10 页：机械专业价值

真正区分普通 RAG 的，是 SOP 和安全合规。系统输出包含断电挂牌、PPE、能量释放、防误启动、工具备件、拆检步骤和验收标准。这些规则来自机械检修流程整理，不允许模型只给泛泛建议。

知识更新也不是自动吸收所有上传内容。一线案例上传后，系统会抽取设备、故障、原因、措施和经验总结，进入待审核状态；审核通过后才进入案例库、知识图谱和检索索引，避免错误经验污染知识库。

## 第 11-12 页：评测和演示

评测不是为了堆数字，而是为了证明系统比无 RAG、文本 RAG、多模态 RAG 更稳。我们关注 Recall@5、引用覆盖率、SOP 完整度、幻觉率和安全漏检。当前 PPT 展示的是项目内部自动评测结果，后续正式答辩会明确说明评测边界。

现场演示按五步走：文本问诊、图片检索、SOP 生成、合规拦截、案例审核更新。每一步只证明一个能力，避免现场随机问答导致演示不可控。

## 第 13-14 页：部署和创新点

部署上，我们准备了公网演示、Supabase 持久化和本地 SQLite 备份。提交前重点不是继续堆功能，而是保证冷启动、数据恢复、截图、视频和说明书都可复现。

我们的创新点可以收束成六个词：领域垂直、证据可追溯、多模态检索、机械 SOP、知识闭环、量化评测。也就是把通用多模态大模型真正落到设备检修的证据链、作业链和知识链。

## 第 15 页：真实系统截图

这一页展示真实系统截图，不是概念图。五张截图分别对应文本问诊、图片检索、SOP 生成、合规校验和案例审核。它们和 A1 的多模态检索、标准作业指引、知识更新要求是一一对应的。

## 第 16 页：自动评测结果

这里展示的是 104 道已审核评测题上的自动对比结果。我要特别说明，这不是第三方权威测试，也不代表系统在所有场景都没有错误。它证明的是在当前设备范围和当前评测集内，检索、引用和 SOP 链路可以稳定跑通。

## 第 17 页：机械审核摘要

这一页证明机械专业不是挂名参与。案例库和评测题都经过 reviewer 代号审核，并给出了故障机理、SOP 完整度和安全合规评分。分数不是满分，说明我们保留了真实复核意见，也说明 SOP 仍有继续打磨空间。

## 第 18 页：公网部署验证

最后是公网部署验证。Render 服务当前可访问，健康检查返回 ok，Supabase 已启用，同时保留本地 SQLite 备份。这个页面证明作品不是只在开发机上运行的脚本，而是具备在线演示和恢复能力。正式答辩前我们还会再跑一次冷启动和核心流程复测。

## 结尾 20 秒

总结一下，我们没有把 A1 做成一个泛泛的多模态问答，而是围绕设备检修现场的证据、流程、安全和知识沉淀做闭环。我们的目标是让一线人员更快找到可靠依据，更规范地执行检修步骤，并把经验持续沉淀到系统里。谢谢各位老师。

## 必须避免的说法

- 不说“模型能直接判断故障”，要说“模型基于检索证据辅助判断”。
- 不说“评测 100% 所以没有问题”，要说“当前评测集内链路稳定，仍需扩展更难样本”。
- 不说“系统替代检修负责人”，要说“系统辅助提醒和规范作业，关键步骤需人工确认”。
- 不说“国产化部署已完成”，除非有真实国产环境截图和测试记录。
