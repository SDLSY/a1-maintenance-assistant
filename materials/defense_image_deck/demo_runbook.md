# A1 答辩演示 Runbook

适用场景：现场答辩 4-5 分钟演示，或录制 3-5 分钟作品演示视频。  
适用系统：本地 `http://127.0.0.1:8051` 或公网 `https://a1-maintenance-assistant.onrender.com`。  
原则：每一步只证明一个能力，不现场自由发挥；如果网络或模型不稳定，立即切换截图/视频兜底。

## 演示前准备

1. 打开 PPT 第 12 页，说明演示路线：文本问诊、图片检索、SOP 生成、合规校验、案例审核更新。
2. 打开系统首页，确认设备范围为电机、泵、轴承。
3. 准备一张泵/轴承故障图片，优先使用已截图链路对应图片。
4. 准备一个固定文本问题，不临场随机输入。
5. 准备本地和公网两套入口；公网冷启动慢时先用本地。

## 固定文本输入

```text
设备：三相异步电机
故障现象：运行 20 分钟后轴承端温升明显升高，伴随周期性异响，机座振动增大。
问题：请给出可能原因、排查步骤、检修 SOP、安全注意事项和验收标准。
```

## 图片演示口径

讲解不要说“图片直接得到答案”，而是说：

> 系统先把图片转成结构化缺陷描述，例如油污、磨损、裂纹、泄漏痕迹，再和手册、案例、设备部件图谱做混合检索。最终回答必须回到证据来源。

## 评委追问时的收束话术

- 如果问“为什么不用通用问答”：我们的主线是检修作业闭环，问答只是入口。
- 如果问“100% 指标准不准”：这是当前 104 道已审核题上的内部自动评测，证明链路跑通，不包装成第三方权威测试。
- 如果问“模型不稳定怎么办”：模型层可替换，检索资产、案例库、图谱和本地备份不依赖单一模型。
- 如果问“能不能落地”：当前证明第一阶段闭环可运行，企业落地需要接入真实手册、工单和权限审核。

## 录制视频建议

1. 前 10 秒用 PPT 第 1 页和一句话定位开场。
2. 中间 3 分钟录系统真实操作，不剪掉等待过程，但可以加速空白加载。
3. 后 40 秒展示第 16-18 页证据：评测、机械审核、部署。
4. 不展示任何 API key、环境变量文件、后台密钥、模型中转站页面。
5. 最终视频文件名建议：`A1-maintenance-assistant-demo-YYYYMMDD.mp4`。
