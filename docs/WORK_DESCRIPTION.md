# 作品说明书

作品名称：A1-MAKG：面向设备检修的多模态证据链作业辅助系统

面向赛题：中国软件杯 A1 - 基于多模态大模型技术的设备检修知识检索与作业系统

## 摘要

本作品面向工业、能源、制造等场景中的设备检修作业，聚焦电机、离心泵、轴承三类典型设备，构建“证据链 + 作业票 + 安全校验”的检修作业辅助平台。系统支持设备型号、故障文本、故障图片等多类型输入，通过公开维修手册、团队自建案例、知识图谱和多模态大模型能力，输出可追溯的故障判断、标准化 SOP、合规校验和验收标准。

系统采用 FastAPI + Vue 3 + SQLite 的轻量架构，文本、视觉和 embedding 能力通过云端模型 API 接入，便于在 LoongArch + 银河麒麟环境中部署应用、索引和编排服务。系统内置案例上传审核、人工修正、知识图谱更新、评测面板和 readiness audit，形成“检索 - 作业 - 审核 - 沉淀 - 评测”的完整闭环。

## 系统功能

### 问诊检修

用户选择设备类型、输入设备型号、检修等级和故障描述，可上传故障图片。系统返回：

- 诊断结论
- 可能原因
- 风险等级
- 检修前安全确认
- 工具备件
- 分步骤 SOP
- 合规检查项
- 验收标准
- 手册引用和相似案例

### 多模态检索

系统将故障文本、设备型号和图片 caption 统一作为检索上下文。检索层同时使用关键词召回、向量召回、设备过滤、图谱扩展和案例召回，避免单次 Top-K 检索误召回。

### 标准作业辅助

SOP 生成以机械检修流程为中心，固定输出结构，强调停机、断电挂牌、泄压/降温、PPE、防误启动、拆检、复装、试运行和验收。系统将规则校验和模型复核结合，减少安全漏项。

### 案例沉淀

一线案例默认进入待审核状态，审核通过后写入案例库、知识图谱和检索索引。未审核案例不会直接污染正式知识库。

### 人工修正

用户可以记录模型原答案、修正答案和备注。后续相似问诊会返回人工修正提示，形成持续改进闭环。

### 知识图谱

知识图谱节点包括设备、部件、故障、风险、流程、案例等，边表示包含、导致、检查、处置、需要等关系。前端提供轻量可视化，便于答辩展示知识沉淀效果。

### 评测与审计

评测面板比较无 RAG、文本 RAG、多模态 RAG 和本系统。readiness audit 检查真实资料、索引、模型路由、审核包、提交包、机械审核和 LoongArch 实机状态，避免把开发验证误判为正式完成。

## 技术实现

### 后端

- FastAPI 提供 REST API。
- SQLite 存储文档、chunk、案例、图谱、反馈、向量和评测结果。
- 检索逻辑位于 `backend/app/retrieval.py`。
- SOP 与 Agent 编排位于 `backend/app/agents.py`。
- 合规规则位于 `backend/app/compliance.py`。
- 模型路由位于 `backend/app/model_gateway.py`。

### 前端

- Vue 3 静态页面。
- 本地 vendor 依赖，避免答辩现场断网导致前端不可用。
- 页面包括问诊检修、案例审核、知识图谱、评测面板、资源与模型。

### 模型路由

| 角色 | 默认 Provider | 默认模型 |
|---|---|---|
| 文本诊断 | codex | gpt-5.5 |
| 图片描述 | codex | gpt-5.5 |
| embedding | openrouter | qwen/qwen3-embedding-8b |
| 合规复核 | codex | gpt-5.5 |
| 知识沉淀 | codex | gpt-5.5 |

系统保留本地规则兜底，模型不可用时仍可演示基本检索和 SOP 流程。

## 创新点

1. 领域垂直：聚焦电机、泵、轴承，故障机理和 SOP 更可控。
2. 证据可追溯：回答必须展示手册页码、来源 URL 和许可说明。
3. 多模态检索：文本、型号、图片 caption、向量检索和图谱扩展共同召回。
4. 作业而非问答：输出标准作业指引、合规校验和验收标准。
5. 知识沉淀闭环：案例审核、图谱更新、人工修正复用。
6. 量化评测：内置对比评测和 readiness audit，明确效果和缺口。
7. 国产环境友好：LoongArch 部署侧只运行轻量应用和索引，不本地跑大模型。
